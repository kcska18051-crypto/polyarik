# Вход для презентации

Прямой запрос пользователя: в интерактивном прототипе по нажатию «Войти» сразу открывать кабинет без логина и пароля; удалить подпись с демонстрационными учётными данными. Это относится только к демонстрации и не является требованием отключать авторизацию на рабочем Битрикс.

Кнопка гостя и ссылки входа в шапке/мобильной панели/корзине активируют существующий демонстрационный профиль. На странице кабинета показываем запрошенный раздел, с других страниц переходим в кабинет. Вход сохраняется в сессии вкладки. Регистрация нового профиля и состояние повторного покупателя сохраняют прежние различия для показа скидок/бонусов. Выход возвращает гостевой экран.

Форма логина/пароля, восстановление фиктивного пароля и подсказка с учётными данными больше не выводятся. Отображение тестовых сумм/операций не маскируется под реальные пользовательские данные.
