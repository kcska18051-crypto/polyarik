# Вход для презентации

Прямой запрос пользователя: в интерактивном прототипе по нажатию «Войти» сразу открывать кабинет без логина и пароля; удалить подпись с демонстрационными учётными данными. Это относится только к демонстрации и не является требованием отключать авторизацию на рабочем Битрикс.

Уточнение после проверки скидки заказа: кнопка гостя и ссылки входа в шапке/мобильной панели/корзине открывают профиль нового покупателя для демонстрации первого заказа с 5%, вместо прежнего профиля с примером заказа №29. При повторном входе его состояние сохраняется: уже использованные 5% не восстанавливаются. Фиктивные старые заказы этого профиля не показываются. На странице кабинета показываем запрошенный раздел, с других страниц переходим в кабинет. Вход сохраняется в сессии вкладки. Явная новая регистрация начинает новый демонстрационный профиль. Выход возвращает гостевой экран. При переходе с предыдущей опубликованной версии один раз выйти и войти, чтобы выбрать новый презентационный профиль.

Форма логина/пароля, восстановление фиктивного пароля и подсказка с учётными данными больше не выводятся. Отображение тестовых сумм/операций не маскируется под реальные пользовательские данные.
