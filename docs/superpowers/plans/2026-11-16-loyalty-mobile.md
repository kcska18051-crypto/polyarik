# Loyalty and mobile implementation plan

Goal: реализовать согласованную скидку новичка, демонстрационное списание бонусов и компактную мобильную навигацию.

Architecture: loyalty.js хранит только состояние демонстрационного профиля и рассчитывает скидки/бонусы. prototype.js отображает единый расчёт в корзине, оформлении и CSV; account.js использует тот же профиль для бонусного кабинета. Общий prototype.css отвечает за мобильную навигацию.

Tech stack: vanilla JS/CSS, Node test runner, jsdom.
