# Повторная проверка прототипа «Полярик»

Источники: расшифровка встречи 19.11.2026, краткий протокол, [реестр из 40 пунктов](2026-11-20-meeting-register.md) и последующие уточнения. Ниже статусы по актуальной версии.

| Пункты реестра | Результат |
|---|---|
| 1–7. Шапка, поиск, телефоны, звонок, значки, бонусы | Оптовое описание и поиск по каталогу на месте. В шапке два номера, избранное и корзина рядом. В мобильной панели сравнения нет. Бонусы показываются вошедшему пользователю. «Заказать звонок» теперь открывает демоформу. Отправку нужно подключить в Битриксе. |
| 8. Миграция клиентских данных | Задача рабочего сайта. Нужны исходная база, проверка совместимости авторизации и перенос связей с заказами и бонусами. |
| 9–13. Каталог | Верхние названия сохранены. Шапки, шлемы, трикотажные модели, летние головные уборы и комплекты с шарфами присутствуют в дереве. На мобильном подкатегории раскрываются внутри меню. |
| 14–20. Акции, спецпредложения и меню | Акции и четыре товарные подборки разведены. «Условия работы» содержит оплату и доставку, «Как оформить заказ» доступно в подвале. У «О компании» есть контакты и новости. Виды производства открываются через боковое меню. Акции и тексты производства ждут утверждения. |
| 21–24. Главная, галерея и рекомендации | Галерея вынесена на отдельную страницу с четырьмя альбомами. На главной сохранены баннер и преимущества, убраны дублирующие категории. Рекомендации открывают 7 карточек, затем ещё 8, затем ссылку в раздел. |
| 25–27. Сортировка, коллекции, образы | Структура меню задана отдельно в JSON. Административная сортировка при обмене с 1С остаётся задачей бэка. «Коллекции» видны в прототипе с пометкой о скрытии при запуске. У пяти демонстрационных образов есть отдельные карточки со связанными товарами. Нужны реальные фото и составы. |
| 28–31. Публикации и новости | Позднее решение заменило «Актуальную информацию» блоком «Свежие события». Есть списки, отдельные статьи и архив. На широком экране списки по четыре карточки. Архивный статус задан вручную в демоданных. Управление статусом из редакторской панели остаётся задачей Битрикса. Новости компании сохранены. |
| 32. Отзывы | В прототипе демонстрируется локальная премодерация. Роли сотрудников, хранение и публикация требуют рабочего бэка. |
| 33. Подвал | Четыре товарные группы, каталог и подборки, оптовикам, оформление, оплата, доставка, производство, галерея, образы, о компании, контакты, новости, свежие события и архив. Убраны тестовые телефонные ссылки. Для рабочего сайта нужны утверждённые ссылки на юридические документы. |
| 34–36. Оформление | Тариф необязателен. Название своей ТК обязательно только при выборе «Ваша транспортная компания». Другой получатель указывается одним полем ФИО и телефоном. Выбор страховки сохранён. Список ТК расширяется после получения данных. |
| 37. Мобильная версия | Нижняя панель: каталог, избранное, корзина, кабинет. Каталог также есть в меню с раскрываемыми подкатегориями. Шапка закрепляется, показывает минимум заказа и сумму корзины. |
| 38–40. ПТД, тестовая база, сроки | Требования собраны. Рабочая интеграция с 1С, перенос данных, оценка и доступы относятся к отдельному этапу. |

У Аспро: Максимум восемь вариантов футера и отдельно настраиваемые ссылки меню. В демоверсии также вынесены контакты и юридические документы. Источники: [типы футера](https://aspro.ru/docs/course/course46/lesson2406/), [меню футера](https://aspro.ru/docs/course/course46/lesson2407/), [демоверсия](https://max-demo.ru/).

Автоматическая проверка: 70 тестов. Проверка в Chromium: 36 маршрутов при ширине 320, 390 и 1440 px, включая детальные страницы товара, образа, альбома, статьи, новости, акции, направления производства и страницы заказа. Проверены раскрытие мобильного каталога, состав нижней панели, ссылки в подвале и демоформа обратного звонка, отсутствие горизонтального переполнения и ошибок JavaScript. Формы и расчёты прототипа используют локальные данные.
