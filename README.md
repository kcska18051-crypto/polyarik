# Полярик — прототип каталога

Версия 58. Статический прототип на HTML, CSS и JavaScript.

Распакуйте содержимое ZIP в корень репозитория. Все страницы и ресурсы находятся в `dist/`. Этот каталог можно отдавать любым статическим веб-сервером.

Для локального просмотра из корня репозитория выполните:

```bash
python -m http.server 8000 --directory dist
```

Откройте http://localhost:8000/. Локальный HTTP-сервер нужен для загрузки данных каталога из JSON. Устанавливать зависимости и собирать проект не требуется.

Личный кабинет, заказы и формы работают в демонстрационном режиме.

## Проверки для разработки

Для запуска проверок навигации нужен Node.js:

```bash
npm ci
npm test
```

Эти зависимости нужны только для тестов. Для просмотра сайта по-прежнему достаточно статического HTTP-сервера.
